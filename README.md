# 떡상 발굴기 (YouTube 떡상 영상 분석 도구)

구독자 수 대비 조회수가 폭발한 "떡상 영상"을 찾아주는 웹 도구입니다.
서버 없이 `index.html` 하나로 동작하며, 본인의 **YouTube Data API v3 키**를 사용합니다.

## 기능
- 키워드 검색엔진: 구독자 구간 / 기간 / 길이(숏폼·롱폼) / 국가 / 정렬 / 떡상 기준 / 영상 수(최대 500) 필터
- 떡상 지수(조회수 ÷ 구독자) 순 정렬, 등급(초대박·대박·떡상·양호·보통) 표시
- 라이브 방송·구독자 비공개 채널 자동 제외, 필터링 통계 표시
- 해외 국가 검색 시 키워드 자동 번역
- 트렌드 키워드 발굴: 국가별 인기 급상승 200개 영상에서 키워드 추출 → 클릭 한 번으로 검색
- 키 지갑: 여러 API 키 등록, 할당량 소진 시 자동 전환, 사용량 게이지
- 영상 저장, CSV 내보내기, 다크/라이트 모드, 모바일 대응

## 사용 방법
1. `index.html`을 브라우저로 열거나, GitHub Pages로 배포합니다.
   (저장소 Settings → Pages → Branch 선택 → Save 하면 `https://<아이디>.github.io/<저장소>/` 주소가 생깁니다.)
2. 오른쪽 위 🔑 버튼을 눌러 YouTube Data API v3 키를 등록합니다. (발급 방법은 앱 안의 "사용 가이드" 참고)
3. 키워드와 조건을 선택하고 **떡상 영상 발굴** 클릭!

API 키와 저장한 영상은 해당 브라우저의 localStorage에만 저장됩니다.
