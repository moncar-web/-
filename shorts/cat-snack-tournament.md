## 3. 떡상 포인트 체크리스트

- [ ] **첫 1초에 소리 + 눈 클로즈업** — 스크롤 멈추게 하는 핵심. 인트로·로고 절대 금지
- [ ] **12초 "과연 선택은?!" 정지 컷** — 중간 이탈 방지
- [ ] **ASMR 구간 BGM 제거** — 씹는 소리가 곧 보상
- [ ] **3위 반전 리액션** — 공유·댓글 유발 ("우리 애도 저럼 ㅋㅋ")
- [ ] **마지막 장면 = 첫 장면** — 자연 반복 재생 → 시청 지속률 100%+
- [ ] 총 길이 **28~32초** 유지 (길면 완주율 하락)
- [ ] 자막: 굵은 흰 글씨 + 검정 테두리, 화면 중앙~상단 1/3 (하단 UI에 가리지 않게)

## 4. 촬영 가이드

1. **로우앵글**: 폰을 바닥에 눕혀 고양이 눈높이. 먹방은 그릇 옆 10cm 초근접
2. **소리 녹음**: 폰 마이크를 그릇 쪽으로. 가능하면 핀마이크를 그릇 밑에 테이프로 고정
3. **공복 타이밍**: 밥 먹기 1~2시간 전에 촬영하면 리액션이 2배
4. **간식 배치**: 식감이 다른 3종(바삭 동결건조 / 부드러운 츄르 / 쫄깃 저키) → 소리 대비가 확실
5. **여러 테이크**: 5~6번 찍어 가장 극적인 반응만 편집 (원본은 길게, 편집은 짧게)
6. **변형 룰(2편용)**: 종이컵 3개에 숨기고 앞발로 툭 쳐서 고르기 → 시리즈화
