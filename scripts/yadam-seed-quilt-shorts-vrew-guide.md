# Vrew 쇼츠 제작 가이드 — 헌 솜이불 한 채

## 1. 준비물
- 대본: `yadam-seed-quilt-shorts-vrew.txt` (그대로 복사해서 붙여넣기)
- 이미지 10장: `yadam-seed-quilt-shorts-9x16-prompts.md`의 01~10번으로 생성, 파일 이름을 `01.png` ~ `10.png`로 저장

## 2. 프로젝트 만들기
1. Vrew 실행 → **새로 만들기** → **텍스트로 비디오 만들기**
2. 화면 비율: **쇼츠 (9:16)**
3. 영상 스타일: 이미지는 직접 넣을 것이므로 기본 스타일 선택 (AI 이미지 자동 생성은 끄거나, 생성 후 교체)
4. 대본 입력 칸에 txt 내용을 그대로 붙여넣기
   - 빈 줄로 나뉜 덩어리 하나가 컷 하나, 줄바꿈 한 줄이 자막 한 줄이 된다.
5. AI 목소리: 차분하고 낮은 톤의 중년 여성 또는 남성 이야기꾼 목소리, 속도 **1.0~1.1배**
   - 목표 길이 55~60초. 짧으면 속도를 0.95배로 낮추고, 길면 1.1배로 올린다.

## 4. 이미지 넣는 법
- 각 컷을 클릭 → 오른쪽 **이미지·비디오** 메뉴 → **배경으로 넣기**로 해당 번호 이미지를 넣는다.
- 자동 생성된 AI 이미지가 있으면 교체한다.
- 이미지 움직임: 컷마다 **천천히 줌인** 또는 **좌우 패닝**을 번갈아 넣으면 정지 이미지라도 영상처럼 보인다.

## 5. 자막 디자인
- **상단 고정 자막** (모든 컷, 화면 위 20% 영역): 텍스트 추가 → 전체 구간 적용
  - 1줄(노랑): 딸 혼수로 헌 이불 한 채 보낸 어머니
  - 2줄(흰색, "절대 뜯지 마라"만 핫핑크): "봄까지 절대 뜯지 마라"
- **내레이션 자막** (Vrew 자동 자막): 화면 가운데 아래쪽, 흰 글씨 + 검정 외곽선, 크고 굵게. 화면 맨 아래 20%는 유튜브 버튼에 가리므로 피한다.
- **강조 자막** (편집표의 굵은 글씨): 각 컷에 따로 텍스트 추가, 화면 가운데에 크게.
