사용 가이드

이 도구는 YouTube Data API v3를 직접 호출해서, 구독자 수에 비해 조회수가 비정상적으로 높은 “떡상 영상”을 찾아줍니다. 서버 없이 브라우저에서만 동작하며, API 키는 이 브라우저(localStorage)에만 저장됩니다.

1. API 키 발급 (무료, 5분)

  1. Google Cloud Console 접속 → 상단에서 새 프로젝트 생성
  2. 왼쪽 메뉴 API 및 서비스 → 라이브러리 → “YouTube Data API v3” 검색 → 사용
  3. API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키
  4. 생성된 키(AIza...)를 복사해서 오른쪽 위 🔑 현재 키 또는 키 지갑에 붙여넣기
  5. (권장) 키 제한 → “API 제한사항”에서 YouTube Data API v3만 허용

2. 할당량(쿼터)

키 1개당 하루 10,000 유닛이 무료입니다. 태평양 시간 자정(한국 시간 오후 4시, 서머타임 해제 시 오후 5시)에 초기화됩니다.

작업소모 유닛
검색 50개약 102 (검색 100 + 영상정보 1 + 채널정보 1)
검색 500개약 1,020
트렌드 키워드 발굴약 4

키 지갑에 키를 여러 개 넣어두면, 하나가 소진됐을 때 자동으로 다음 키로 전환합니다.

3. 떡상 지수 계산 방식

  • 떡상 지수 = 조회수 ÷ 구독자 수 (예: 구독자 1만 명 채널 영상이 30만 회 → 30배)
  • 결과는 기본적으로 떡상 지수가 높은 순으로 정렬됩니다.
  • 구독자 수 조건·길이 조건에 맞지 않는 영상, 라이브/예정 방송, 구독자 수 비공개 채널은 자동 제외됩니다.
  • “떡상 기준”보다 지수가 낮은 영상은 ‘떡상 영상’ 수에는 포함되지 않지만, 결과 목록 아래쪽 “기준 미달”에서 볼 수 있습니다.

4. 팁

  • 키워드 없이 기간 + 구독자 조건만으로 검색하면 해당 기간 전체에서 떡상한 영상을 찾을 수 있습니다.
  • ‘1천~1만(소형)’ + ‘최근 7일’ + ‘숏폼’ 조합이 신규 채널 벤치마킹에 가장 유용합니다.
  • 결과는 CSV로 내려받아 엑셀에서 정리할 수 있습니다.
